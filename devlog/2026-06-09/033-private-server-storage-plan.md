# 033. 개인 서버 기준 저장 구조 전환 계획 문서화

- 날짜: 2026-06-09
- 요청: "그 다음에 작업해야될게 뭐야? 회원정보/러닝기록 RDS 저장 구조 전환인가? 근데 이제 나는 RDS, S3, 이런 아마존 클라우드가 아닌 개인 서버로 일단은 할건데 어떻게 변경해야될까?"

## 변경 파일

- `docs/private-server-storage-plan-2026-06-09.md`
- `devlog.md`
- `devlog/2026-06-09/033-private-server-storage-plan.md`

## 작업 내용

- AWS RDS/S3 전환 항목을 개인 서버 기준의 운영 DB, 로컬 파일 저장소, 백업 구조로 재정의했다.
- 현재 프로젝트의 DB 모델, JSON 데이터 파일, 이미지/영상 저장 경로를 확인해 문서에 반영했다.
- 다음 P0 작업명을 `회원정보/러닝기록 개인 서버 운영 DB 저장 구조 전환`으로 제안했다.

## 확인 결과

- 회원/인증 일부는 DB 모델 기반이고, 러닝 기록과 관련 서비스 데이터는 JSON 파일 기반임을 확인했다.
- 러닝 이미지와 사진/영상은 `/opt/app/data/run_images`, `/opt/app/data/run_media` 기본 경로의 로컬 파일 저장 구조임을 확인했다.
