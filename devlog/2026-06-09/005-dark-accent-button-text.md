# 다크 모드 민트 포인트 버튼 텍스트 대비 보정

- **ID**: 005
- **날짜**: 2026-06-09
- **유형**: 디자인 수정

## 작업 요약
다크 모드에서 민트 포인트 배경을 쓰는 버튼/탭의 텍스트가 흰색으로 남아 있던 지점을 보정했다.
라이트 모드의 기존 대비는 유지하고, 다크 모드에서만 `--primary-ink` 검정 계열 텍스트가 적용되도록 오버라이드를 추가했다.

## 원문 요청사항
```text
다 좋은데 다크모드일 때 포인트 컬러 들어간 버튼에 텍스트가 흰색인 애들이 있거든 텍스트 컬러를 검정색으로 변경해줘
```

## 변경 파일 목록
- `src/app/page.dashboard/view.scss`: 다크 모드의 민트 포인트 액션 버튼/탭/칩 텍스트를 `var(--primary-ink)`로 보정.
- `devlog.md`, `devlog/2026-06-09/005-dark-accent-button-text.md`: 작업 이력 기록.

## 확인 결과
- WIZ `wiz_project_build(clean=false)` 통과.
- `background: var(--primary)`와 흰 텍스트를 함께 쓰는 블록 목록이 다크 모드 오버라이드 대상과 일치하는지 확인.
