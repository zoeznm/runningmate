# AI 채팅 새날 안내와 민트 포인트 컬러 전역화

- **ID**: 004
- **날짜**: 2026-06-09
- **유형**: 디자인 수정

## 작업 요약
새날 안내가 떠 있을 때 기본 페이서 메시지가 바로 노출되지 않도록 비우고, 사용자가 `새 대화`를 선택했을 때만 기본 대화 메시지가 시작되도록 조정했다.
AI 채팅에서 사용한 민트 계열을 다크/라이트 모드별 포인트 컬러 변수로 확장하고 기존 보라 포인트 하드코딩 값을 변수 기반으로 치환했다.

## 원문 요청사항
```text
바뀐 UI를 보면 새 대화 . 기록 보기 저게 상단에 뜨고 있어 근데 하단에 이미 새 대화를 시작하고 있어 그래서 새 대화를 선택해야지 하단에 페이서가 저렇게 대화를 바로 하게 해줘 그리고 포인트 컬러가 이 앱의 포인트 컬러랑 맞지 않는거 같은데 나는 이 색이 좀 더 좋다고 생각이 들거든? 지금 다크 모드 라이트모드 일 때 판단해서 지금 Ai 채팅에 쓴 포인트 컬러를 가지고 전체 앱의 포인트 컬러를 변경해줄 수 있어?
```

## 변경 파일 목록
- `src/app/page.dashboard/view.ts`: 새날 안내 상태에서 기본 AI 메시지를 자동 생성하지 않도록 조정하고, 데이터 갱신 중에도 안내 상태를 유지.
- `src/app/page.dashboard/view.scss`: 민트 계열 포인트 컬러 토큰을 다크/라이트 모드에 추가하고 기존 보라 포인트 색상을 변수 기반으로 교체. 새날 안내 버튼 줄바꿈 방지 스타일 추가.
- `devlog.md`, `devlog/2026-06-09/004-ai-chat-prompt-accent-color.md`: 작업 이력 기록.
