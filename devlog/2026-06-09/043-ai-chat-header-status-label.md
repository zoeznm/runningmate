# AI 채팅 헤더 상태 문구를 세션 제목과 분리

## 사용자 요청

AI 채팅에서 페이서 아래에 사용자가 처음 보낸 텍스트가 그대로 나오는데, 그대로 노출하지 않고 다르게 나오게 하면 좋을지 문의했다.

## 변경 파일

- `src/app/page.dashboard/view.ts`
- `devlog.md`
- `devlog/2026-06-09/043-ai-chat-header-status-label.md`

## 변경 내용

- AI 채팅 상단의 `activeChatTitle`이 활성 대화 세션 제목을 그대로 노출하지 않도록 변경했다.
- 활성 세션이 있을 때는 `밸런스 페이서`, `코치형 페이서`처럼 현재 페르소나 상태를 보여주도록 했다.
- 답변 생성 중에는 `답변 준비 중`, 새날 안내 상태에서는 `새 하루 준비`, 세션이 없으면 `새 대화`를 표시하도록 정리했다.
