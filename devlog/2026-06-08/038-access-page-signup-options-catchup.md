# 로그인/회원가입 화면 UX 변경 catch-up

- **ID**: 038
- **날짜**: 2026-06-08
- **유형**: UX 개선 catch-up

## 작업 요약
이전 같은 리뷰 세션에서 처리한 로그인 화면 위치 조정, 세로 스크롤 방지, 회원가입 방식 선택 화면 추가 작업을 누락된 devlog로 보강했다.
회원가입 진입 시 카카오/네이버/구글/이메일 선택 화면을 먼저 보여주고, 이메일 선택 시 기존 회원가입 폼으로 이동하도록 정리했다.

## 원문 요청사항
```text
처음에 이 어플을 딱 들어왔을 때 위에 로고가 좀 더 내려오고 회원가입을 누르면 일단 그냥 버튼만 만들어주는건데
카카오톡으로 쉬운시작 하나랑, 네이버로 쉬운시작 하나랑 구글 계정으로 쉬운시작 하나랑 이메일로 회원가입 이런식으로 나오게 해줘 그리고 현재의 회원가입 나오는거는 이메일로 회원가입 눌렀을 때 나오는 화면으로 해줘 일단은

그리고 지금 로그인 페이지가 세로 스크롤이 되거든 세로 스크롤이 되지 않게 해줘 무조건 한 페이지에서 끝나야돼.
```
