## 작업 요약
목표 화면의 챌린지 탭을 목록, 상세, 생성 흐름으로 분리했다.
챌린지 생성 성공 후 인라인 완료 컴포넌트가 남지 않게 했고, 참여중/모집중/내가 만든/종료 탭별 목록과 상세 화면 이동을 정리했다.
내가 만든 챌린지는 별도 탭에서 확인하고 삭제할 수 있도록 API와 UI를 추가했다.

## 원문 요청사항
```text
작업 진행해줘

목표 탭에서 챌린지 탭에서 수정해야될 점이 많음.
1. 챌린지 생성한 후 : 챌린지 생성됨 이라는 컴포넌트 없애줘
2. 챌린지 생성한 후 : 참여중에 챌린지 상단에 보여주는데 그 아래에 또 챌린지를 보여주는 섹션이 있음. 목록처럼 내가 참여하고 있는 챌린지를 보여준 후에 그 해당 챌린지 클릭하면 해당 챌린지만 보여주는 따로 페이지로 이동을 해서 거기에 디데이, 진행도, 참가자, 참가자별 기여도 이런걸 보여주면 좋겠음.
3. 챌린지 생성한 후 : 하단에 챌린지 생성이 있음. 근데 이거를 차라리 맨 위에 참여중, 모집중, 종료 탭메뉴 아래에 버튼으로 챌린지 생성하기 라고 버튼을 둬서 그거 클릭하면 챌린지 생성할 수 있는 버페이지로 이동하면 좋겠음.
4. 내가 만든 챌린지 보기 : 내가 만든 챌린지를 보고싶은데 어디서 보여주면 좋을지 모르겠어 (너가 추천해줘)그리고 거기에는 내가 만든 챌린지니까 챌린지 삭제 기능 버튼도 있으면 좋겠어
5. 모집중 탭을 누르면 표시할 챌린지가 없다고 떠 근데 내가 만든 챌린지도 있으니 그거가 뜨면 좋겠고 만약에 아무런 챌린지가 없다면 표시할 챌린지가 없어라고 뜨는게 맞아. 모집중 챌린지에도 동일하게 목록 리스트 형태로 챌린지들이 뜨면 좋겠고 그 리스트에서 클릭하면 상세보기 페이지로 챌린지보여주는 페이지로 이동하면 좋겠어.
6. 종료 탭을 누르면 지금은 모집중에 있는 페이지랑 동일한 거 같은데 종료에는 여기도 동일하게 없다면 표시할 챌린지가 없어 라고 뜨면 좋겠고 있다면 목록 리스트 형태로 뜨고 종료라는 태그를 달아줘 그리고 참여중인 챌린지는 참여중 이라는 태그를 달아주고 모집중인 챌린지에는 모집중이라고 달아줘 그리고 내가 모집중인 챌린지에 참여하게 되면 참여중이라고 태그가 바뀌고 내가 참여중인 챌린지가 종료되면 종료태그로 바뀌게 해주고 모집중인것도 종료되면 종료 태그로 변경해주면 돼. 다시 돌아와서 종료에서도 목록 리스트로 보여주고 누르면 챌린지 상세보기 페이지로 넘어가주면돼.
```
