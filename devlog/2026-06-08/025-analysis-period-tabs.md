# 025. 분석 기간 탭 이번주/저번주/월별로 변경

## 원 요청

월별이랑 전체랑 보여주는데 의미가 없는 거 같애 차라리 전체탭을 없애도 될 것 같애
아니면 이번주, 저번주, 월별 이렇게 나오면 어떨까?

## 변경 파일

- `src/app/page.dashboard/view.pug`
  - 분석 기간 탭을 `이번주`, `저번주`, `월별`로 변경했습니다.
  - 의미가 불분명한 `전체` 탭을 제거했습니다.
- `src/app/page.dashboard/view.ts`
  - 분석 차트 기간 타입을 `this_week`, `last_week`, `monthly`로 정리했습니다.
  - 이번주/저번주 탭은 각 주의 7일 단위 막대그래프를 표시하도록 변경했습니다.
  - 기간별 요약과 비교 문구가 선택한 기간 기준으로 계산되도록 보정했습니다.
- `devlog.md`
- `devlog/2026-06-08/025-analysis-period-tabs.md`

## 확인 결과

- `rg`로 기존 `weekly`, `all` 분석 기간 UI 참조가 남아 있지 않은 것을 확인했습니다.
- `wiz_project_build(clean=false)`로 프로젝트 빌드 성공을 확인했습니다.

## 남은 리스크

- 실제 브라우저 화면 캡처 검증은 진행하지 않았습니다.
- 이번주/저번주 기준은 러닝 기록이 있으면 최신 기록 날짜의 주를 기준으로 잡고, 기록이 없으면 오늘 날짜를 기준으로 잡습니다.
