# 대시보드 초기 인증 복구 및 로그인 필요 오류 노출 방지

- **ID**: 045
- **날짜**: 2026-06-08
- **유형**: 버그 수정

## 작업 요약
대시보드 초기 진입 시 인증 복구보다 데이터 API 호출이 먼저 실패해 "로그인이 필요합니다." 메시지가 노출될 수 있는 흐름을 보강했다.
공통 API 호출은 보호된 API의 401 응답에서 refresh token으로 한 번 복구를 시도하고, 대시보드는 초기 데이터 로딩 전에 인증 상태를 먼저 확인하도록 수정했다.

## 원문 요청사항
```text
다시는 그러지 않게 잘 수정해줘
```

## 변경 파일 목록
- `src/angular/app/shared/auth.ts`
  - 보호된 API URL 판별 함수를 export했다.
  - `ensureAuthenticated()`가 만료됐을 수 있는 access token만으로 인증 통과하지 않도록 수정했다.
- `src/angular/app/shared/api.ts`
  - 보호된 API에서 401이 발생하면 refresh token으로 인증을 복구한 뒤 요청을 1회 재시도하도록 추가했다.
- `src/app/page.dashboard/view.ts`
  - 초기 데이터 로딩 전에 로그인 상태 확인 단계를 추가했다.
  - 초기 러닝 기록 로딩에서 최종 401이 남으면 "로그인이 필요합니다." 오류를 화면에 띄우지 않고 로그인 화면으로 이동하도록 처리했다.
