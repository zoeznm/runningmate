# 브랜드 스플래시 및 초기 로딩 개선

## 배경
- 비로그인 사용자는 첫 진입 시 로그인 화면이 바로 보이기보다 브랜드 로고와 `RunMate`를 먼저 보여주는 흐름이 필요했다.
- 로그인 사용자의 대시보드 초기 로딩은 반투명 오버레이와 고정 문구 대신 브랜드 중심의 전체 화면 로딩으로 정리해야 했다.
- 기록, 목표, 커뮤니티 데이터는 초기 로딩 단계에서 먼저 준비된 뒤 메인 화면이 보여져야 했다.

## 변경
- 앱 셸, 접근 화면, 공통 전체 화면 로더를 검은 배경의 로고 + `RunMate` 중심 화면으로 통일했다.
- 접근 화면은 비로그인 사용자에게 최소 2초 스플래시를 보여준 뒤 로그인/회원가입 UI를 표시하도록 조정했다.
- 대시보드 초기 로딩은 하단 팁 문구가 순환되도록 바꾸고, 기존 반투명 서비스 로딩 오버레이를 제거했다.
- 대시보드 초기 단계에서 전체 러닝 기록, 기록 메모/휴식일/날씨, 목표/챌린지, 커뮤니티 피드/친구/알림/랭킹을 먼저 불러오도록 했다.

## 확인
- 브랜드 스플래시 템플릿에서 기존 `초기 데이터`/`자동 로그인 확인` 문구가 노출되지 않도록 정리했다.
- 전체 로딩 컴포넌트는 기존 `message` 입력 호환성을 유지하면서 화면에는 브랜드와 팁만 표시한다.
