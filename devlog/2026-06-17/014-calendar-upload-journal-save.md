# 기록 업로드 일기 저장 버튼 추가

## 요청

기록 화면에서 오늘의 일기를 적은 뒤 저장하는 버튼이 보이지 않는 문제를 수정해달라는 요청.

## 변경

- 기록 업로드 카드의 오늘의 일기 입력 영역 아래에 `일기 저장` 버튼과 저장 상태 문구를 추가했다.
- 버튼이 화면 아래로 밀려 보이지 않을 수 있어 오늘의 일기 제목 오른쪽에도 항상 보이는 저장 버튼을 배치했다.
- 러닝 기록을 아직 업로드하지 않은 날짜에서도 일기 텍스트를 날짜별 저장소(`/api/day-notes`)에 저장하거나 지울 수 있게 했다.
- 날짜를 바꾸거나 메모 데이터를 다시 불러올 때 저장된 날짜별 일기 텍스트가 입력칸에 동기화되도록 했다.
- 기존 러닝 기록을 재업로드/수동 수정할 때 숨겨진 업로드 일기 값이 기존 기록의 일기를 덮어쓰지 않도록 journal payload 포함 범위를 새 기록 저장으로 제한했다.
- 현재 운영 번들이 정식 Angular 빌드 실패로 갱신되지 않아, 제공 중인 `bundle/www/main.js`에도 일기 저장 버튼을 직접 반영했다.
- 기존 서비스워커 런타임 캐시가 오래된 `main.js`를 반환하지 않도록 PWA 캐시 버전을 `runningmate-pwa-v49-journal-gallery`로 올렸다.

## 확인

- `http://127.0.0.1:3000/main.js` 응답에 `일기 저장` 버튼 문자열이 포함되는 것을 확인했다.
- `http://127.0.0.1:3000/main.css` 응답에 `upload-journal-head-save` 스타일이 포함되는 것을 확인했다.
- `http://127.0.0.1:3000/sw.js` 응답에 `runningmate-pwa-v49-journal-gallery` 캐시 버전이 포함되는 것을 확인했다.
- 정식 Angular 빌드는 기존 프로젝트 타입/스타일 오류로 실패하며, 이번 일기 저장 버튼 관련 오류는 확인되지 않았다.
